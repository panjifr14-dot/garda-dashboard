# Garda Data Muda - Dasbor Akuntabilitas Publik

Prototipe dasbor publik untuk memantau agregat kinerja kader verifikasi lapangan, sanggah di Pojok Sanggah, rujukan layanan sosial, dan pelaporan keluhan warga secara anonim.

Bagian dari proyek esai ASF 2026: **Garda Data Muda**.

## Fitur Dasbor
- **Agregat Tanpa Identitas:** Menampilkan rekapitulasi status verifikasi tanpa membocorkan data pribadi atau nama warga.
- **Pemantauan Sanggah & Rujukan:** Memantau jumlah rujukan terkirim dan sanggah yang masuk.
- **Kanal Keluhan Terbuka:** Form pengaduan keluhan warga per kecamatan.
- **Standalone & Terhubung:** Dapat dijalankan secara mandiri (static preview) maupun terhubung dengan backend Express/SQLite dari [garda-data-muda](https://github.com/panjifr14-dot/garda-data-muda).

## Menjalankan
Cukup buka file `index.html` langsung di browser Anda, atau hosting menggunakan GitHub Pages.
